dw_core.adapters.mixins.TaskETAListener

class dw_core.adapters.mixins.TaskETAListener[source]

Implementation of TaskETAListenerInterface.

This implementation maintains a list of ETA callbacks and notifies all registered callbacks when the ETA is updated.

Example

>>> class MyTask(TaskETAListener):
...     def run(self):
...         self.set_eta(60)  # 60 seconds remaining
...         # do work
...         self.set_eta(30)  # 30 seconds remaining
...         # do more work
...         self.set_eta(0)   # task complete
