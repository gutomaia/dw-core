CQRS Module

This module provides the base classes for implementing CQRS pattern.

Class Overview

CQRSRequest

Base class for all CQRS requests.

CQRSResponse

Base class for all CQRS responses.

Command

Base class for command requests in CQRS pattern.

Query

Base class for query responses in CQRS pattern.

Event

Base class for domain events in CQRS pattern.

CQRS Pattern Classes

class dw_core.cqrs.Command(**data)[source]

Bases: CQRSRequest

Base class for command requests in CQRS pattern.

Commands represent intentions to change the system state. They are named with imperative verbs and should be processed exactly once. Examples include: CreateUser, UpdateProfile, DeleteAccount.

model_config: ClassVar[ConfigDict] = {}

Configuration for the model, should be a dictionary conforming to [ConfigDict][pydantic.config.ConfigDict].

class dw_core.cqrs.Query(**data)[source]

Bases: CQRSResponse

Base class for query responses in CQRS pattern.

Queries represent requests for information that do not modify system state. They can be executed multiple times without side effects. Examples include: GetUserProfile, ListOrders, SearchProducts.

model_config: ClassVar[ConfigDict] = {}

Configuration for the model, should be a dictionary conforming to [ConfigDict][pydantic.config.ConfigDict].

class dw_core.cqrs.Event(**data)[source]

Bases: BaseModel

Base class for domain events in CQRS pattern.

Events represent facts that have occurred in the system. They are named in past tense and are immutable. Examples include: UserCreated, OrderPlaced, EmailSent.

model_config: ClassVar[ConfigDict] = {}

Configuration for the model, should be a dictionary conforming to [ConfigDict][pydantic.config.ConfigDict].
