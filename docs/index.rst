Welcome to Downwind Core documentation!
=====================================

Downwind Core is a Python module that implements CQRS (Command Query Responsibility Segregation) pattern with domain-driven design principles.

Core Features
------------

* CQRS implementation with Command, Query, and Event base classes
* Pluggable architecture using entry points
* Domain-driven design support
* Modular and extensible design
